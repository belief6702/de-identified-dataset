# 电商业务数据说明

本目录包含订单、订单明细、支付、评价、客户、商户、商品及邮编位置记录，共八张 UTF-8 编码 CSV。字段定义见 `数据字典.md`。空字段表示未记录或不适用；时间字段为未附时区的本地业务时间，不宜与外部事件直接校准。金额均使用统一记账单位 CU，不能据此换算成特定现实货币。

订单是业务记录，商品明细、支付和评价分别按各自记录粒度保存。不同表的记录数量可能不同；一笔订单可能有多条明细、支付或评价。客户表按账户记录，`person_id` 标识客户主体。商品与商户表可含观察期内没有订单记录的条目。

邮编位置表允许一个邮编出现多条位置记录，位置字段使用本数据的局部坐标参考。坐标不是可直接对应外部地图的标准地理位置，不能直接用于计算现实道路距离或跨区域实际公里数。部分客户、商户邮编没有位置记录。品类、城市和区域为内部编码，未附外部名称映射。

该数据没有商品成本、平台费用、退款流水、广告投入、访问曝光或完整客户生命周期记录。支付记录表示记录内的付款金额，不能单独代表利润或扣除退款后的净收入。订单状态、时间戳、商品属性及评价可能存在缺失；评价标识与订单关系以实际记录为准。观察期边界可能不覆盖完整月份或客户后续行为。
